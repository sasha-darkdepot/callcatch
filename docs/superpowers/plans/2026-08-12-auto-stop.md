# Auto-Stop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When a recording that started automatically ends its call, stop it after a visible 10 s draining-button countdown — hover pauses, ✕ keeps recording, click stops now.

> **Superseded in implementation:** the drain is driven by a 30 Hz Timer in
> RunLoop `.common`, NOT `TimelineView(.animation)` as written below —
> TimelineView doesn't tick in an inactive app (live-hit; see the spec and
> AGENTS.md "unfocused-app family"). The spec's Status header lists all
> post-review deltas.

**Architecture:** All decision logic lands in `AppState` behind the injected scheduler plus a new injected monotonic clock (fully unit-tested with `MockScheduler` + mock clock). Adapters get a mask-based draining button (Timer-driven), an `NSTrackingArea(.activeAlways)` hover trigger with a 1 s parked-cursor recheck, a menu toggle, and a registered-default setting.

**Tech Stack:** Swift 6 / SwiftPM, XCTest, SwiftUI + AppKit adapters.

**Spec (authoritative for all semantics):** [`docs/superpowers/specs/2026-08-12-auto-stop-design.md`](../specs/2026-08-12-auto-stop-design.md) — arming invariant, cancellation table, hover failsafes, retry, copy.

## Global Constraints

- FSM timing ONLY via injected scheduler + injected `now: () -> TimeInterval` (default `ProcessInfo.processInfo.systemUptime`); new constructor closures are **defaulted** so the existing 61 tests compile unmodified.
- Countdown = one optional value; **every** cancellation path nils it entirely (timer + paused remainder).
- Drain visual: capsule fill under a leading-aligned straight-edge mask — never `scaleX` the capsule. Hover highlight = color nudge only, animated.
- English UI strings; text weight ≤ medium; zero third-party deps; macOS 26 floor.
- `swift test` green before every commit; branch `auto-stop`, merge to main when done.
