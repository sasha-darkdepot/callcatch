# CallCatch

Menu bar приложение для macOS: ловит начало звонка в **Discord, Signal,
Telegram (обе версии), WhatsApp** по использованию микрофона и показывает бабл
внизу экрана с кнопкой «Записать в Plaud». Когда звонок закончился, а запись
ещё идёт — предлагает остановить. Решает проблему: Plaud сам не детектит
звонки в этих приложениях (у него зашит белый список: zoom/teams/slack/…).

## Как это работает

- **Детект** — CoreAudio Process Objects API (macOS 14.4+): системные события
  «процесс начал/закончил использовать микрофон». Без поллинга и разрешений.
- **Старт записи** — deep link `plaud://record?auto=1&user_id=…` (механизм
  веб-интеграции Plaud) с подтверждением по логу Plaud и ретраями при
  холодном старте.
- **Стоп** — Accessibility-клик по кнопке стопа в окне Plaud (требует
  разрешения Accessibility); fallback — поднять окно Plaud (`plaud://open`).

## Сборка и установка

```bash
INSTALL=1 bash scripts/build-app.sh   # собрать, подписать и поставить в /Applications
open /Applications/CallCatch.app
```

Сборка подписывается сертификатом Apple Development (если он есть в связке
ключей) — благодаря стабильной подписи разрешение Accessibility сохраняется
между пересборками. Без сертификата используется ad-hoc-подпись (тогда
Accessibility приходится выдавать заново после каждой сборки).

## Первый запуск

1. `user_id` подхватывается из логов Plaud автоматически. Если иконка
   показывает ⚠️ «user_id не найден» — открой [web.plaud.ai](https://web.plaud.ai),
   нажми Record (при запущенном десктопном Plaud), перезапусти CallCatch.
2. При первом нажатии «Записать» / «Остановить» macOS спросит разрешение
   **Accessibility** — выдай его CallCatch (System Settings → Privacy &
   Security → Accessibility). Без него не работает только стоп-кнопка
   (старт записи — работает).
3. «Запускать при входе» — в меню иконки.

## Меню

- **Записать сейчас** — ручной старт во время звонка (если бабл закрыт).
- **Остановить запись** — всегда доступный стоп (пока идёт запись CallCatch).
- **Авто-запись** — старт записи через 7 сек после начала звонка без клика.

## Известные ограничения

- Авто-режим отсекает только использования микрофона короче 7 сек: голосовое
  сообщение в Telegram длиннее 7 сек запустит запись.
- Программного стопа у Plaud не существует — стоп работает через
  Accessibility-клик; при обновлении Plaud может понадобиться перекалибровка
  (`PlaudAX.stopButtonNeedles`); fallback — окно Plaud поднимается само.
- Если приложение отпускает микрофон при mute, длинный mute (>5 сек)
  выглядит как конец звонка — появится бабл «Звонок завершён» (безвредно).
- Проверено на Plaud v1.3.7; тонкая семантика deep link недокументирована.
